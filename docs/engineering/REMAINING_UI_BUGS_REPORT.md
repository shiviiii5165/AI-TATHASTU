# Remaining dashboard UI bugs: root causes and fixes

Scope: AI Tathastu (`dev/ai-tathastu`) only. Base: `main` @ `4e93266`, with the earlier three-bug fixes uncommitted in the tree (kept intact).

| Bug | Root cause | Fix | Files |
|---|---|---|---|
| A. Skill Proficiency bars dull | Fill was `bg-primary` (verified) or `bg-muted-foreground` (others): one near-black colour for every skill | Gradient fills from a fixed 7-colour palette (violet→pink, blue→cyan, indigo→sky, purple→violet, orange→amber, teal→emerald, pink→rose). A skill's colour is picked from a hash of its name, so it's stable across renders. Glowing endpoint dot; skill icon chip; level badge (Advanced green, Proficient blue, Working violet, Foundational orange); real `%` on the right. Bars grow from zero to the actual score once on mount (`skillBarGrow`, 900 ms, 80 ms stagger, `transform: scaleX`, so the element's real width is the score from the first paint). Reduced motion: `motion-reduce:animate-none` plus the global reduced-motion rule leaves a static, correct bar. Card size, layout, 7-row limit, scores and the View all link are unchanged. | `growth-development-row.tsx`, `globals.css` |
| B. Skill Gaps / Learning Paths styling | Monochrome rows, priority badges with only border colour | Gaps: coloured icon tile per skill, High/Medium/Low badges (rose/amber/sky), subtle hover. Learning: one soft-tinted tile per recommendation with an icon, title, link, and provider and duration only when the catalogue has them. No module counts are shown, because the catalogue has none. Recommendation logic is unchanged. | `growth-development-row.tsx` |
| C. Career Roadmap | A single progress bar and a stage list | Curved SVG path (violet→fuchsia gradient), nodes for Current / Short / Mid / Long term, rocket endpoint, captions from the user's own roadmap. The gradient path is drawn only to the engine's evidence coverage (`roadmapDraw`). The next milestone's node pulses (motion-safe). Clicking a stage node shows its milestone with its status and a **Submit evidence** form. See `CAREER_ROADMAP_VALIDATION_REPORT.md`. | `growth-development-row.tsx`, `lib/roadmap/*`, `dashboard/roadmap-actions.ts`, migration `0025` |
| D. Yora Quick Actions panel | The panel listed actions with no working behaviour | Removed from the overview row. Journey and Skills Intelligence now span 6/12 columns each and keep their content height. `QuickActionsPanel` and Yora's services, routes and modal are untouched; Yora still opens from the hero and Next Actions. | `dashboard-view.tsx` |
| E. LeetCode under "Patents & Honors" | `worker/connectors/coding_profiles.py` writes LeetCode/HackerRank stats as `achievements` facts (record keys `leetcode:stats` / `hackerrank:stats`; ERIS reads them there). The achievements page put every non-publication, non-certification record into "Patents & Honors". | A shared classifier `lib/profile/coding-activity.ts` routes those record keys to a new **Coding Activity & Problem Solving** section (source, total, Easy/Medium/Hard, badges, the profile it came from, and an "Imported from public profile" status, since account ownership isn't verified). The dashboard's achievements count and Honours list, and the Journey, exclude them too. Stored rows are not changed. | `achievements/page.tsx`, `achievements/coding-activity-section.tsx`, `lib/dashboard/stats.ts`, `lib/profile/coding-activity.ts` |
